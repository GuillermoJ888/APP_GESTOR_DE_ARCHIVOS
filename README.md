# 📁 Gestor de Archivos - Android

Aplicación Android para la gestión básica de archivos, desarrollada como proyecto de la materia de Desarrollo Móvil en CESBA.

## 🎯 Funcionalidad
- Guardar archivos de texto en almacenamiento externo privado de la app
- Listar los archivos guardados
- Leer y visualizar el contenido de un archivo seleccionado

## 🛠️ Tecnologías
- Java
- Android Studio
- Almacenamiento externo con `getExternalFilesDir`, `FileOutputStream` y `FileReader`

## 🎨 Interfaz
Diseño con `CardView` (header, editor de texto, lista de archivos y visor de contenido) y drawables personalizados para botones, chips e inputs.
